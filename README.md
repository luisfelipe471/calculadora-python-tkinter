# Calculadora em Python com Tkinter

Aplicação desktop com interface gráfica desenvolvida como **projeto de conclusão de um curso de Python**. O projeto reúne lógica de programação, validação de entradas e construção de interfaces com Tkinter.

## Funcionalidades

- Adição, subtração, multiplicação, divisão, potência e resto da divisão.
- Seleção de operações por botões.
- Histórico de cálculos, com opção para apagar o histórico.
- Validação de entradas numéricas e tratamento de divisão por zero.
- Formatação de resultados, incluindo notação científica quando necessário.

## Tecnologias

- **Python** — lógica e operações.
- **Tkinter** — interface gráfica (biblioteca padrão do Python, normalmente disponível em instalações desktop).
- **math** — verificações e formatação numérica (módulo da biblioteca padrão).

## Como executar

1. Instale o Python 3 com suporte a Tkinter.
2. Baixe ou clone este repositório.
3. Abra um terminal na pasta do projeto.
4. Execute:

   ```bash
   python calculadora.py
   ```

   No Windows, também é possível usar `py calculadora.py`.

> A aplicação usa uma interface gráfica e precisa ser executada em um ambiente desktop com suporte a janelas. Não há dependências externas para instalar via `pip`.

## Sobre o desenvolvimento

Este projeto foi criado para aplicar na prática conhecimentos de Python, organização de funções, tratamento de erros e interação com o usuário por meio de uma interface gráfica.
